# Sete Fusion Cuisine

Site estático exportado para GitHub Pages. Esta versão utiliza a imagem original no hero e não contém o vídeo.

## Publicação

1. Envie todos os arquivos deste diretório para um repositório GitHub.
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`.

O arquivo `index.html` está na raiz e todos os recursos estão em `assets/`.
